# 三人分离的同条件验证

用附带的普通话三人组和英语三人组，各构造三段受控混音。两套模型都使用已知的三人声源数，原生均以 8 kHz 推理，再对齐到同一 16 kHz 评分时间轴。比较程序核对了每份混音和三条参考 WAV 的 SHA-256 以及相同的共同重叠窗。分数是在共同重叠区使用最佳一一配对后的三轨平均 SI-SDRi（dB），即各轨分离后相对原混音的改善。

| 组别 | 条件 | MossFormer2 三人 | SR-CorrNet 三人 |
|---|---|---:|---:|
| 普通话 | 50% 共同重叠 · 等电平 | +9.14 | +7.33 |
| 普通话 | 100% 共同重叠 · 等电平 | +8.47 | +2.68 |
| 普通话 | 100% 共同重叠 · 第三路 −6 dB | +7.77 | +3.60 |
| 英语 | 50% 共同重叠 · 等电平 | +11.34 | +8.63 |
| 英语 | 100% 共同重叠 · 等电平 | +11.96 | +13.58 |
| 英语 | 100% 共同重叠 · 第三路 −6 dB | +12.06 | +7.01 |
| 全部 | 六个条件的等权平均 | +10.12 | +7.14 |

MossFormer2 在 5/6 个条件取得更高的三轨均值，0 个条件打平。全部 18 个单轨分数中，MossFormer2 的最低值为 +6.73 dB，SR-CorrNet 为 +1.21 dB。见 [逐轨对照](comparison.csv)。

测试样本为两组三人朗读，每组重复三种条件。结果反映这两套公开预训练权重在这六份受控混音上的表现。语料处理与许可见 [原声来源](../../samples/three-speaker/来源.md)。复现命令见 [项目说明](../../README.md)。
