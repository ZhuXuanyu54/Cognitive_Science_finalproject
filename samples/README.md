# 音频样本来源与处理

合成英文组：macOS 内置 Samantha（美式英语）与 Daniel（英式英语）合成两段不同文本，均转为单声道、16 kHz、16 位 PCM WAV。两段时长为 4.722 秒和 4.095 秒。

真人英文组：LibriSpeech（OpenSLR 12，CC BY 4.0）中两名不同说话人的音频。第一段为 `1688-142285-0007`（说话人 1688，7.060 秒）；第二段为 `3436-172162-0000`（说话人 3436，截取开头 5.300 秒并结束于语音停顿）。音频转为单声道、16 kHz、16 位 PCM WAV。

原始音频不随仓库分发；可以将合法取得的两段单声道 WAV 传给 `run_pilot.py` 复现流程。
